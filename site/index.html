  1. Scope + research. Question + success criteria; Literature, code + licenses; Sources + open questions.
  2. Preregister. Hypothesis or exploration; Metrics, controls + analysis; Freeze the protocol in Git.
  3. Implement + publish core. Working code + checks; README + reproduction; Push before any training.
  4. Pilot + publish. Smallest useful experiment; Predictions + checkpoint; Publish preliminary findings.
  5. Comparative experiments. Baselines, controls + ablations; Seeds + sensitivity checks; Keep negative findings too.
  6. Analyze + distill. Statistics, intervals + plots; Claims linked to evidence; Reports, paper + explorer.
  7. Review + repair. Code + methodology review; Citations + reproducibility; Repair concrete failures.
  8. Publish + decide. Merge PRs + verify artifacts; GitHub Pages + model bundles; Stop or begin a new cycle.

Each phase builds a fresh context, invokes the selected Claude Code or Codex model, verifies its artifacts, then persists and publishes progress. SQLite retains attempts, budgets and pending handoffs. Research files retain observations; raw logs stay local. Repair and publication recovery use durable evidence. Changed hypotheses after observed results require a new protocol and cycle. The controller's structural checks do not guarantee scientific truth.
