# Settings reference

Generated by `uv run python scripts/console_reference.py` from the same registry used by configuration validation, CLI overrides, and browser forms. See [console controls](console.md) for precedence and recovery semantics. Credentials are not registered settings.

Defaults below are field defaults. Backend defaults resolve an empty model to `haiku` or `gpt-6-luna`; digits profiles retain their historical bounded allowances. The console starts with one completed loop and ordered selection; legacy `mode=cycle` also stops after one completed cycle.
